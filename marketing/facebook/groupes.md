# Statut pour les groupes Facebook

À publier dans les groupes (étudiants, quartiers, transport du Grand Tunis), **avec une image ou une vidéo** : `01-couverture.jpg`, ou une des vidéos de `../video/`. Remplacer `[LIEN DE LA PAGE]` par l'adresse de la page (par exemple https://www.facebook.com/TransTunisLive).

```

Le principe est simple : quand vous êtes dans un bus ou un métro, vous touchez « Je suis dans ce véhicule », et tous les autres voyageurs le voient avancer sur la carte. Vous aidez les autres aujourd'hui, ils vous aident demain. 🤝
```

## Conseils

- **Lire les règles de chaque groupe** avant de publier : beaucoup interdisent la publicité ou demandent l'accord de l'administrateur. En cas de doute, écrire d'abord à l'admin.
- **Publier depuis ton profil personnel** (les groupes acceptent rarement les pages), un groupe par jour environ : publier le même texte partout en même temps peut être bloqué comme spam par Facebook.
- **Varier** : texte complet + image dans certains groupes, vidéo dans d'autres.
- **Répondre aux commentaires**, surtout aux questions (« c'est officiel ? » → non, c'est une application indépendante, non affiliée à la Transtu ; « quand ? » → très prochainement, abonnez-vous à la page).
