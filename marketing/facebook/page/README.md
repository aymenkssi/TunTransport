# Créer la page Facebook TransTunisLive

| Fichier | Où l'utiliser |
|---|---|
| `photo-profil-720.png` | Photo de profil (Facebook l'affiche en rond) |
| `photo-couverture-1640x624.jpg` | Photo de couverture (le centre reste visible sur mobile) |

## 1. Créer la page (10 min)

Depuis ton compte Facebook personnel (il devient administrateur ; ton nom n'apparaît pas sur la page) :

1. Ordinateur : https://www.facebook.com/pages/create · Téléphone : **Menu ☰ → Pages → + Créer**.
2. Remplir :

| Champ | Valeur |
|---|---|
| Nom de la Page | `TransTunisLive` |
| Catégorie (jusqu'à 3) | **Application** (ou « Page d'application »), **Service de transport**, **Site web** |
| Bio (101 caractères max) | `Bus, métro, TGM et trains de Tunis en direct, partagés par les voyageurs 🚌 النقل العمومي مباشرة` |

3. **Créer la Page**, puis :
   - **Photo de profil** : `photo-profil-720.png`
   - **Photo de couverture** : `photo-couverture-1640x624.jpg`
4. Coordonnées :
   - Site web : `https://tuntransport.academy`
   - E-mail : `contact@tuntransport.academy`
   - Téléphone, adresse, horaires : **laisser vide / « Aucun horaire »** (c'est une application, pas un commerce)
5. Les étapes « Connecter WhatsApp » et « Inviter des amis » peuvent être passées, puis faites plus tard.

## 2. Réglages importants

Sur la page : **Paramètres** (ou **⋯ → Paramètres**).

- **Nom d'utilisateur** : `@TransTunisLive` (ou `@TransTunisLive.tn` si pris). L'adresse devient facebook.com/TransTunisLive.
- **Bouton d'action** (sous la couverture → Modifier le bouton) :
  - avant la sortie : **Envoyer un message** ;
  - après la sortie : **Utiliser l'application** (ou « Installer »), avec le lien Play Store `https://play.google.com/store/apps/details?id=com.aymenkssi.tuntransport`.
- **À propos → Infos supplémentaires** : coller le texte ci-dessous.
- **Sécurité** : activer la **double authentification** sur ton compte personnel, et ajouter **une deuxième personne de confiance comme administrateur** (Paramètres → Accès à la Page) pour ne jamais perdre la page.
- **Messages** : activer une réponse automatique (Meta Business Suite → Boîte de réception → Automatisations) :
  ```
  Merci pour votre message ! 🙏 Pour signaler une erreur sur une ligne, vous pouvez aussi utiliser « Envoyer une suggestion » dans l'application (À propos). Nous répondons au plus vite.
  شكرًا على رسالتك! 🙏 للتبليغ عن خطأ في خط، يمكنك أيضًا استعمال «Envoyer une suggestion» في التطبيق. سنرد في أقرب وقت.
  ```

### Texte « À propos »
```
TransTunisLive est le « Waze » des transports en commun du Grand Tunis : les voyageurs à bord partagent la position du bus, du métro, du TGM ou du train, et tout le monde le voit avancer sur la carte en temps réel. Itinéraires avec correspondances, heure d'arrivée à votre arrêt, recherche d'adresse. Gratuit, sans compte.

TransTunisLive هو «Waze» النقل العمومي في تونس الكبرى: الركاب على متن العربة يشاركون موقعها، والجميع يراها على الخريطة مباشرة. مجاني وبدون حساب.

Application indépendante, non affiliée à la Transtu ni à la SNCFT. تطبيق مستقل، غير تابع لشركة النقل بتونس ولا للشركة الوطنية للسكك الحديدية.
```

## 3. Premières publications

Dans **Meta Business Suite** (https://business.facebook.com, ou l'application du même nom) → **Planificateur**, on peut tout programmer à l'avance.

| Jour | Publication | Fichiers |
|---|---|---|
| J1 | Présentation + **épingler** la publication (⋯ → Épingler en haut) | `../01-…07-*.jpg` + texte de `../README.md` |
| J2 | Reel, voix arabe | `../../video/transtunislive-presentation-ar-fr.mp4` |
| J4 | Reel, voix française | `../../video/transtunislive-presentation-fr-ar.mp4` |
| Jour de la sortie | « Disponible sur Google Play » + lien, puis changer le bouton d'action | texte « sortie » de `../README.md` |

Ensuite, environ 2 publications par semaine : une ligne mise en avant, une astuce (« Touchez un arrêt pour l'heure d'arrivée »), les nouveautés de chaque mise à jour, des remerciements aux voyageurs qui partagent.

Pour les Reels : **Créer → Reel**, importer la vidéo, ajouter la description courte et les hashtags, et choisir la miniature `../../video/miniature.jpg`. Ne pas ajouter de sous-titres automatiques : ils sont déjà dans l'image.

## 4. Faire connaître la page

- **Inviter** tes amis (bouton « Inviter » sur la page), et demander aux premiers testeurs de s'abonner.
- **Partager** les publications dans les groupes d'étudiants, de quartiers et de transport de Tunis, en respectant leurs règles.
- **Instagram** (facultatif) : Paramètres de la page → Comptes liés → Instagram, pour publier les mêmes Reels sur les deux.
- **Ne pas** utiliser les logos ou le nom de la Transtu ou de la SNCFT comme s'il s'agissait d'une page officielle : Facebook peut suspendre une page qui semble se faire passer pour un organisme.
- Publicité payante (facultatif, plus tard) : **Booster** une publication ciblée sur le Grand Tunis, 18–45 ans, à partir de quelques dinars par jour, une fois l'application disponible.
